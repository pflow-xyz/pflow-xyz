Test Rate Optimization

This test page demonstrates the rate optimization features for Petri net transition rates. The optimization can find optimal rates to maximize token counts at target places using either continuous or binary optimization strategies.

Simple Example: Two Transitions Competing for Resources

Instructions:

  1. Click the hamburger menu (☰) in the top-left
  2. Select "🧮 Simulate (ODE)"
  3. Choose optimization mode:
    • Continuous: Finds optimal fractional rates (0.0-1.0)
    • Binary: Finds which transitions to fully enable (1.0) or disable (0.0)
  4. If Binary mode is selected, choose the algorithm:
    • SPSA + Local Search (recommended): Efficient stochastic optimization, faster for many transitions
    • Threshold + Local Search (legacy): Traditional gradient-based method
  5. Click "Optimize Rates" button
  6. Select a target place (e.g., "Output A" or "Output B")
  7. Watch the optimization progress
  8. Click "Run Simulation" to see the result

Expected Behavior:

  • Continuous Mode: Finds optimal continuous rate values between 0.0 and 1.0
  • Binary Mode (SPSA):
    • Uses SPSA to find continuous solution (Phase 1)
    • Applies threshold to get binary rates (Phase 2)
    • Refines with local bit-flip search (Phase 3)
    • More efficient than legacy mode (2 evaluations per iteration vs N+1)
  • Binary Mode (Legacy):
    • Uses finite-difference gradient ascent (Phase 1)
    • Same thresholding and local search as SPSA (Phases 2-3)
  • If optimizing for "Output A", transition t1 should get a higher rate
  • If optimizing for "Output B", transition t2 should get a higher rate
  • Both SPSA and legacy algorithms should find similar solutions
