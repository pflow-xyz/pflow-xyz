Test Rate Optimization with Gradient Descent

This test page demonstrates the new gradient descent optimization for Petri net transition rates.

Simple Example: Two Transitions Competing for Resources

Instructions:

  1. Click the hamburger menu (☰) in the top-left
  2. Select "🧮 Simulate (ODE)"
  3. Click "Optimize Rates" button
  4. Select a target place (e.g., "Output A" or "Output B")
  5. Watch the gradient descent optimization find optimal rates
  6. Click "Run Simulation" to see the result

Expected Behavior:

  • The algorithm should use gradient descent instead of brute force enumeration
  • It should find continuous rate values (not just 0 or 1)
  • The optimization should complete in fewer than 100 iterations
  • If optimizing for "Output A", transition t1 should get a higher rate
  • If optimizing for "Output B", transition t2 should get a higher rate
