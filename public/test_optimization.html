Test Rate Optimization

This test page demonstrates the simplified rate optimization for Petri net transition rates. The optimizer uses a simple single-pass algorithm to determine which transitions help or hurt a target objective.

Simple Example: Two Transitions Competing for Resources

Instructions:

  1. Click the hamburger menu (☰) in the top-left
  2. Select "🧮 Simulate (ODE)"
  3. Choose optimization mode:
    • Continuous [0,1]: Transitions determined helpful get rate=1, others rate=0
    • Binary (0|1): Same algorithm, explicitly labeled as binary output
  4. Click "Optimize Rates" button
  5. Select a target place (e.g., "Output A" or "Output B")
  6. Choose whether to maximize or minimize the target value
  7. Watch the optimization progress - simple single-pass algorithm
  8. Click "Run Simulation" to see the result

Expected Behavior:

  • Single-Pass Algorithm:
    • Step 1: Evaluate baseline with all transitions at rate=1
    • Step 2: Test each transition individually by setting it to rate=0
    • Step 3: If removing a transition makes the target worse, keep it (rate=1)
    • Step 3: If removing a transition makes the target better or same, remove it (rate=0)
    • Very fast: Only N+1 evaluations (baseline + one per transition)
    • Works for both maximize and minimize objectives
  • Performance:
    • Much faster than previous gradient-based methods
    • Scales linearly with number of transitions
    • No complex iteration tuning needed
  • If optimizing for "Output A", transition t1 should get rate=1, t2 should get rate=0
  • If optimizing for "Output B", transition t2 should get rate=1, t1 should get rate=0
