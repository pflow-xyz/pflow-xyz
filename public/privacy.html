Privacy policy

Last updated 28 October 2026

pflow.xyz is a free editor and toolset for Petri nets, run by Matt York (stackdump). This page covers the website, its API and its MCP connector at https://pflow.xyz/mcp.

What we collect

  • Nets you save. When you save a net, from the editor, the API or the pflow_save tool, it is stored under its content id (CID). Saved nets are public: anyone with the CID can read them, and they can appear in the sitemap.
  • Who saved a net. A save records the account that made it. With GitHub that is your GitHub user id and username. With Google it is only Google's account id for you; we don't ask Google for your name or email address.
  • Editor sign-in. Signing in to the editor with GitHub asks GitHub for your profile, email address and permission to create gists. The access token goes to your browser; the server uses it to check who you are when you save and keeps only your user id and username.
  • Sign-in records. When an app such as Claude signs you in to the MCP connector, we keep a record of that sign-in (your account id, the app and an expiry date) so the app can stay signed in. It lasts at most 30 days after the app last refreshed it. We never see or store your GitHub or Google password.
  • Request logs. Our servers log each request's method, path, time and IP address, for running and debugging the service.
  • Analytics. The editor's home page and the composition views page (/compose.html) use Google Analytics to count visits, which sends Google the page address, the referring page, your IP address and browser details. The composition page keeps its state in the part of the address after #; we have not checked whether Google's script reports that part, so don't put anything private in it. The MCP connector and the other pages do not use Google Analytics.
  • Your browser's own storage. The editor keeps your working session (your model library and notes) in your browser's IndexedDB, and the composition page remembers a view setting in local storage. These stay on your device; we don't receive them.

What we don't collect

Nets and compositions you send to the MCP tools for checking, simulating or analysing are processed in memory and are not stored. Only pflow_save stores anything. We don't sell data, show ads or build profiles.

Who else sees it

  • GitHub or Google, when you choose to sign in with them, under their own privacy policies.
  • jsDelivr and PyPI (cdn.jsdelivr.net, pypi.org, files.pythonhosted.org), only if you open the Laws view on the composition page: your browser then downloads Pyodide and some Python packages from them (about 24 MB), so they see your IP address, browser details and that the request came from pflow.xyz. Nothing from your models is sent. They are not contacted when the page loads or for the other views.
  • cdnjs (cdnjs.cloudflare.com): the editor loads its code-editor component from there each time it opens, with the same information as above. The editor falls back to a plain text box if it is blocked.
  • GitHub gists, only if you press the editor's create-a-gist button while signed in: the net is posted to your GitHub account using your token.
  • Google Gemini, if you use the editor's drafting or assistant features: the text you type and the net you are working on are sent to Google's Gemini API to produce a reply.
  • Everyone, for nets you save, because saved nets are public.

How long we keep it

Saved nets are kept so that their links keep working. Sign-in records expire as described above. Logs are kept only as long as needed to run and debug the service.

Your choices

You can use every tool except saving without signing in. To ask about your data, or to ask for a saved net or a sign-in record to be removed, open an issue at github.com/pflow-xyz/pflow-xyz/issues. You can also revoke pflow.xyz's access at any time in your GitHub or Google account settings.

Changes

If this policy changes, the new version will be posted here with a new date.
