Example models, open in the editor

Each one is a saved net with a content-addressed ID. Open it, change a weight, run it. The same kind of model is what sim.pflow.xyz builds from a description.

Coffee Shop

Weighted arcs encode recipes, conservation laws guarantee you never oversell a latte.

Tic-Tac-Toe

Every board position is a place. ODE heatmaps reveal optimal play from network topology alone.

Enzyme Kinetics

Producer-Consumer

Draw → Check → Prove

One model, three questions: what is it, what does it do, can it be audited.

Draw

Build state machines visually. Places, transitions, arcs: the model is a directed graph stored as JSON-LD with content-addressed identity.

pflow.xyz

Check

Describe a decision or a process and get back a model that is seeded, repeatable and checked knob by knob, instead of a confident guess. Start from words, not from a canvas.

sim.pflow.xyz →

Prove

ZK circuits verify every transition is valid without revealing state. Groth16 proofs from net topology, so the model carries its own audit trail.
