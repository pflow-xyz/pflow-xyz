Like a list comprehension, pflow starts from a description: say what the system is, and get a model you can run. Then ask it how it is put together, what happens over time, what can't change, what an agent should do, whether reality matches, and whether it is provably right. Under the hood, every model is a Petri net, so runs replay and proofs check.
